# Ценность и каналы «Сноски»

Целевой сегмент из ДЗ-4 — исследователи научно-технических центров, которым перед запуском НИОКР нужно найти прошлые внутренние работы по теме. Ссылки на расшифровки — файл в `interviews/` и номер вопроса по порядку (все B2B-интервью проведены с моделями).

## Критерии успеха целевого сегмента

1. **Нужный внутренний отчёт находится с первого запроса, даже если назван другими словами или лежит сканом, — без 40 минут перебора терминов и похода к коллеге.** Сейчас: «в разные годы одно и то же называли по-разному… пришлось перебирать варианты» (`live-b2b` в. 2); «минут сорок, наверное, потратил, потом просто зашёл к Сергею» (`synthetic-b2b-2` в. 3).
2. **До начала опытов известно, что по теме уже делали и чем это кончилось, — ни недели на повтор.** Сейчас теряют от недели до двух месяцев: «месяцев двух жалко» (`live-b2b` в. 9), «около месяца рабочего времени лаборатории… потеряли» (`synthetic-b2b-1` в. 9), «неделю, в общем, можно было не тратить» (`synthetic-b2b-2` в. 9).
3. **Прошлые справки по смежной теме — свои и чужие — находятся тем же поиском, что и отчёты, а не случайно в разговоре.** Сейчас: «в этот раз сам с трудом её нашёл… если бы её писал кто-то другой, я бы о ней, скорее всего, вообще не узнал» (`live-b2b` в. 11); обзор соседнего отдела «лежал у них на сетевом диске, в общий архив его не регистрировали» (`synthetic-b2b-2` в. 9).

## Три гипотезы ценности

### Гипотеза 1

| | |
|---|---|
| Сегмент | Исследователи научно-технических центров перед запуском НИОКР |
| Работа | Найти все прошлые внутренние работы по теме (ключевая) |
| Критерии успеха | Критерий 1: отчёт находится с первого запроса, без перебора терминов и похода к коллеге |
| Механика | 4. Починить обрыв цепочки — шаг 2 из ДЗ-4: поиск по архиву не находит отчёт, названный другими словами или лежащий сканом |
| Что уходит из стоимости пользователя | Время на перебор запросов (40 минут и больше на одну тему) и переключение на коллег-старожилов, которые могут и не вспомнить |
| Чем подтверждается | `live-b2b` в. 2, 9; `synthetic-b2b-2` в. 3. Против: `synthetic-b2b-1` в. 3 — там полнотекстовый поиск работает, всё нашлось за два часа |
| Во что обойдётся постройка | 3–4 недели на прототип: распознавание сканов, поиск по смыслу, интерфейс, проверка на открытых научно-технических отчётах. У заказчика — ещё 1–2 месяца на выгрузку архива и согласование с ИБ |

### Гипотеза 2

| | |
|---|---|
| Сегмент | Исследователи научно-технических центров перед запуском НИОКР |
| Работа | Найти прошлые справки по смежной теме (микроработа ключевой) |
| Критерии успеха | Критерий 3: прошлые справки, свои и чужие, находятся поиском, а не случайно |
| Механика | 2. Устранить работу — искать справки по почте, личным папкам и сетевым дискам больше не нужно: каждая справка при отправке попадает в общий индекс |
| Что уходит из стоимости пользователя | Поиск по почте и чужим дискам и риск вообще не узнать о справке коллеги — сейчас узнают случайно |
| Чем подтверждается | `live-b2b` в. 11; `synthetic-b2b-2` в. 9, 11 |
| Во что обойдётся постройка | Около недели поверх гипотезы 1: папка или форма для отправки справки и её индексация. Скрытая стоимость — новая привычка: справку нужно туда положить |

### Гипотеза 3

| | |
|---|---|
| Сегмент | Исследователи научно-технических центров перед запуском НИОКР |
| Работа | Не профинансировать повтор уже проведённого исследования (большая работа) |
| Критерии успеха | Критерий 2: до начала опытов известно, что по теме уже делали и чем кончилось, — ни недели на повтор |
| Механика | 5. Снизить стоимость: риск — каждая новая тема или заявка автоматически сверяется с архивом, и до начала опытов исследователь получает список похожих прошлых работ с их итогами |
| Что уходит из стоимости пользователя | Риск потерять от недели до двух месяцев работы лаборатории на опыты, которые уже ставили |
| Чем подтверждается | `live-b2b` в. 9; `synthetic-b2b-1` в. 9; `synthetic-b2b-2` в. 9 — во всех трёх случаях о прошлой работе узнали случайно, от коллеги |
| Во что обойдётся постройка | 1–2 недели поверх гипотезы 1: сравнить описание новой темы с индексом и выдать сводку похожих работ. У заказчика нужен доступ к тому месту, где регистрируют новые темы |

## Ранжирование

1. **Гипотеза 1** — без её индекса не работают гипотезы 2 и 3; закрывает обрыв, который описан в двух интервью из трёх. Самая дорогая, но обязательная.
2. **Гипотеза 3** — самый большой прирост на один случай (недели–месяцы работы лаборатории) всего за 1–2 недели поверх гипотезы 1.
3. **Гипотеза 2** — самая дешёвая, но польза копится медленно: индекс справок пополняется по мере их написания и зависит от новой привычки.

## Карта партнёров и каналов

| Канал / партнёр | Почему через него дотянемся до сегмента | Как попробуем |
|---|---|---|
| Корпоративные ИИ-хакатоны промышленных компаний | Задачи таких хакатонов уже про работу с внутренними знаниями R&D; есть опыт участия (хакатон металлургической компании, июль 2026) | Написать организаторам и менторам хакатона, показать прототип гипотезы 1 и попросить 30 минут с сотрудником научно-технического центра — проверить, работает ли у них поиск по архиву |
| Научно-технические библиотеки и службы научно-технической информации центров | Именно к ним сегмент идёт сегодня за отчётами и статьями вне подписки (`live-b2b` в. 7, `synthetic-b2b-1` в. 9); они владеют архивом и сканами | Через индустриальных партнёров университета найти сотрудника такой службы; спросить, какая доля отчётов — сканы без текста, и предложить распознать пробную выборку |
| ИТ-команда внутреннего корпоративного ИИ-ассистента | Ассистент уже есть внутри контура (`live-b2b` в. 7); встроиться в него проще, чем проходить ИБ отдельным продуктом | Через организаторов хакатона или индустриальных партнёров университета выяснить, видит ли ассистент архив отчётов о НИР; если нет — предложить поиск по архиву как модуль к нему |
